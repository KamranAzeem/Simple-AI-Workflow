# v6.8.0

This release makes your global user directory and your default shell configurable.

Set `Global User AI Directory` and `Default Shell` in `ai-customization.md`. Set the optional `Default Shell Path` in your global settings. The AI now reads your customization first, then your whole settings directory, before the first shell command.

The defaults do not change. `[HOME]/.ai/` stays the global directory, and your current shell behavior stays when you set no keys. The sync scripts verify the user directory when it is present and add no new keys. The bootstrap creates the configured directory.

The backup command now quotes every path, so a global directory with spaces works.
