# v6.10.2

This patch removes the protocol index helper from the boot path.

- The boot builds its module index with the assistant's built-in reader, glob, and search. It no longer runs a script to build the index.
- Windows Git Bash no longer waits on process spawns during load context, so a slow helper can no longer look like a hang.
- The load proof reports `index-source=builtin`.
- `support-files/index-protocol.sh` remains as an optional maintainer tool for exact checks and release verification. A manual run uses `timeout 20`.
- The release check matched 39 modules, 24 policies, 15 procedures, 50 triggers, 0 conflicts, and 0 errors.
