# Simple AI Workflow v5.7.0

Released 2026-11-07.

## You are told when the workflow clone is behind

Load context now checks the Simple-AI-Workflow clone named in your `ai-customization.md`. It compares the clone with its remote and reports one line in the load summary:

- Up to date, with the short commit ID.
- Updates available, with both short IDs and the exact `git pull` command.
- The clone is ahead of the remote, or the two have diverged. The clone should not be modified, so this is reported as a warning.
- The check was skipped, with a short reason. Offline, missing git, a zip download, and a slow remote all take this path.

The check is read-only. It never fetches, pulls, or changes a file. It sets no credentials, discards command output, and stops after about three seconds when the network is unavailable. It runs at load context only, never at checkpoint.

## Upgrade

Pull the latest workflow and run the sync script as usual. No customization change is needed.
