# Simple AI Workflow v6.0.0

Released 2026-11-09.

## A thin AGENTS.md and a procedure store

The 13 procedures now live in `ai/procedures/`, one self-standing module each. `AGENTS.md` keeps the always-on rules, the shared index step, and the dispatch. The boot payload is about three quarters smaller.

- Say `"load context"`, `"checkpoint"`, `"peer review"`, or any existing phrase; the module triggers work as before.
- A new procedure is a new module; no `AGENTS.md` edit.
- Procedure modules use `# PROCEDURE <NAME>: ...` and `## Triggers`.
- The setup appendix moves to `docs/setup.md`.
- The procedure store lives in the clone, so a project keeps only its own `AGENTS.md` and `ai-customization.md`.

## Upgrade

Pull the latest workflow, run the sync script, and restart the session. The sync script updates `AGENTS.md`; the procedures load from the clone.
