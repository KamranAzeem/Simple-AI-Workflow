# v7.8.0

This release adds a presentation standard and a simpler diagram pipeline, and it updates the deck to the v7.7.x scope and store names.

- `ai-policy-presentation.md` sets the narrative, layout, type, source, diagram, and review rules; trigger `presentation standards`.
- New or changed diagrams can use D2 or Mermaid sources with a 32-unit floor and a manifest. The guide's compaction diagram and the deck's six-level ladder keep their existing SVGs.
- The protocol counts are 26 policies, 16 procedures, 59 triggers, and 33 test scripts.
- Release: [v7.8.0](https://github.com/KamranAzeem/Simple-AI-Workflow/releases/tag/v7.8.0)
- Upgrade: pull and run the sync; no migration.
