# Simple AI Workflow v5.4.0

Released 2026-10-29.

> **Superseded by v5.4.1.** The line-based limits and split behavior are replaced; use the v5.4.1 standard.

## Knowledge files now have a standard

Every file in `ai/shared/project-knowledge/` and `~/.ai/global-knowledge/` now starts with a visible header that points at the rules. After that, it follows one shape: Context, Rule or Fix, Why, Verify, and Caveats if there's a catch.

Keep one lesson per file. Keep it at or below 100 lines. Use flat bullets, not tables. Leave out commit hashes, branch names, checkpoint and diary references, and state-file paths. Those are bookkeeping, not knowledge. `issue-template.md` and design docs in the old fallback location are exempt.

The checkpoint checks the header before it writes. It also flags a missing header, a table, or a file that has grown too long. It never edits your knowledge files.

## Repair with a manifest and a backup

Say `"repair knowledge files"` when you want the AI to fix the project store. Add `global` for global knowledge, `both` for both, or `dry run` to see the plan first.

Heads up: it takes a while on a real knowledge base. Let it finish. It's important; it's how your files get fixed.

The repair reads the files first, builds a list of every item and where it will go, backs up the old files, writes a candidate, checks that nothing was lost, runs a review, and asks before it deletes, merges, or moves anything. If something fails, it puts the backup back. The 100-line target never beats keeping the content.

## One branch per work item

A local ticket now uses one branch and one squash commit. The plan, code, tests, docs, release notes, ADRs, ticket close, and plan appendix stay on the branch. The plan needs an Evidence section and automatic review rounds. The final plan goes into the closed ticket, and the plan file is deleted.

## Cleaner updates

The sync script no longer copies the workflow clone into its own target. It also skips an identical file and keeps going if one target fails, so one bad project doesn't stop the rest. The protocol file now carries a visible banner that says it's a protocol file, not project context.

## Backlog cleanup

Three experiments left the backlog: wayfinding, the AI coding dictionary, and the Sandcastle analysis. The decisions are in the protocol decision store. The full analyses are not part of the shipped corpus.

## Upgrade

1. Pull the latest workflow and run the sync script as usual.
2. Run `"repair knowledge files"` once in each project. It takes a while; let it finish.
3. Add `global` if you keep global knowledge.

Run it once. It fixes your files. Nothing breaks while you wait; the checkpoint flags the issues but does not edit anything.
