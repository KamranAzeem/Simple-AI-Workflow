# v6.11.0

This minor release adds out-of-band backup scripts.

- `support-files/backup-ai.sh` and `support-files/backup-ai.ps1` back up the `ai/` directory and `ai-customization.md` of every project under a search path. No AI assistant is required.
- A project is marked by `ai-customization.md`, or by `ai/state/` and `ai/shared/`. The workflow clone is skipped.
- Archives go to `$HOME/.ai/backups/` by default, one `.tar.gz` per project, named `<parent>_<project>_<date>_<HH-MM>.tar.gz`. `--backup-dir` and `-BackupDir` override the location.
- Secrets are included by default and the archive is owner-only on POSIX. On Windows the script applies an owner-only ACL when it can. `--exclude-secrets` and `-ExcludeSecrets` leave them out.
- `--dry-run` and `-WhatIf` list the projects and archive names without writing.
- The interactive `"backup ai"` command is unchanged. `support-files/README.md` documents both paths.
- No policy or procedure change. The ADR records the scope.

Upgrade: pull the clone. The sync script is unchanged.
