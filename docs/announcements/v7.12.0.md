# v7.12.0

Grilling now asks sharper rounds, so a plan is settled with fewer, better questions.

- A round asks only the decisions whose prerequisites are settled. No two dependent questions share a round.
- Each question is numbered and titled, with one recommended answer on its own line, so a round can be answered by number.
- The agent resolves facts by reading and checking; the user makes the decisions, and the agent never settles one on the user's behalf.

- Upgrade: pull and run the sync; no migration.
