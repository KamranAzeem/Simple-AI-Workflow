# v7.10.0

The sync role list no longer lives in the scripts. `--list-presets` reads the live presets directory, and role validation follows it.

- `--list-presets` (Bash) and `-ListPresets` (PowerShell) print the live preset slugs, sorted, one per line.
- Both scripts drop the fixed role list. The init usage keeps one `web-developer` example.
- A removed preset is an unknown role. A missing or empty directory is a packaging error. A symlink preset is invalid.
- A consistency test ties the guide table and the setup example to the live directory, so a missing or extra preset fails before release.
- Release: [v7.10.0](https://github.com/KamranAzeem/Simple-AI-Workflow/releases/tag/v7.10.0)
- Upgrade: pull and run the sync; no migration.
