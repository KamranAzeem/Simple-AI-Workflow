# v7.7.0: Four scopes and one migration

Released 2026-11-25. Release: [v7.7.0](https://github.com/KamranAzeem/Simple-AI-Workflow/releases/tag/v7.7.0)

The protocol now uses four scope names: Workflow, User, Team, and Project. The word "global" no longer names a scope. Knowledge stores use the same unprefixed `knowledge/` directory name in the user, team, and project scopes.

## What changes

- The keys are `Workflow AI Directory`, `User AI Directory`, `Team AI Directory`, and the derived directory keys. The old keys are removed by the sync migration, with no key alias window.
- The user area gains `skills/`, and the user knowledge store becomes `knowledge/`.
- The project knowledge store becomes `ai/knowledge/`. `ai/shared/` keeps `coordination.md` and `handoffs/`.
- The team store becomes `<Team AI Directory>/knowledge/`.
- `ai-policy-global-settings.md` becomes `ai-policy-user-settings.md`.
- `repair-global-settings` becomes `repair-user-settings`.
- `docs/global-user-settings.md` becomes `docs/user-settings.md`.
- The settings file `global-user-settings.md` becomes `user-settings.md` in the user settings directory.
- Skills precedence is project, then team, then user, then workflow.

## Upgrade

1. Pull the workflow clone.
2. Preview the sync with `--dry-run` on Linux or Git Bash, or `-WhatIf` on Windows PowerShell 7+.
3. Run the sync to migrate each initialized target. It backs up the project store under `ai/artifacts/scope-migration-<date>/project-knowledge/`, the user store under `<User AI Directory>/backups/scope-migration-<date>/user/`, and the team store under `<User AI Directory>/backups/scope-migration-<date>/team/`.
4. Review and commit the team repository changes; the sync never commits or pushes.
5. Restart the session and run `load context using AGENTS.md protocol`.

The sync refuses an uninitialized target and points to `bootstrap using AGENTS.md protocol`. It refuses a symlink at the customization path. A failed backup leaves that store unchanged and reports which store failed.

## Compatibility

- A legacy layout is read-only at boot and warns once per root.
- The old trigger phrases work through v7.7.x and are removed in v7.8.0.
- Historical announcements, closed tickets, and old ADR entries keep their original vocabulary.
- Git's own global configuration keeps the word "global"; it is the tool's term.

## Verification

- `bash support-files/validate-protocol.sh` checks the keys, the mandatory directories, the user and workflow stores, and the new support files.
- `bash tests/run-all.sh` runs the full suite, including the path probe, the migration fixture, the four skill roots, and the docs audit.
- The index contract reports `scope=workflow` or `scope=project`.
