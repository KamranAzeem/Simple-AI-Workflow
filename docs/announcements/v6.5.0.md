# Simple AI Workflow v6.5.0

Released 2026-11-13.

## Handoff creation

A handoff now has a dedicated policy, a creation procedure, and a review gate. Say `create handoff`; the AI loads `ai-policy-handoff.md`, drafts the handoff under `ai/artifacts/handoffs/<handoff-slug>/`, runs a peer review, and writes the final handoff only after APPROVED.

The policy owns the ordered template: Objective, Authorization, Read first, Scope, Starting facts, Steps, Binding rules, Shared output paths, Report back, Review, and Verification. The common policy keeps the always-on refusal pointer and the branch-gating exception pointer.

A receiver may merge the branch when the review, the Verification, and the conditional autonomy conditions pass. The receiver does not write the three state files; the original orchestrator records the state at the next checkpoint and deletes the handoff.

The handoff stays internal by default. The outbound content scrub applies only when it leaves the project. The fence-aware validator fix also stops fenced example headings from polluting the module index.

## Upgrade

Pull the workflow, run the sync script, and restart the session. No repair is needed.
