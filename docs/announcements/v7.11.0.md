# v7.11.0

The last temporary trigger aliases are gone. The protocol now ships 55 triggers.

- `update global knowledge` is removed. Use `update user knowledge`.
- `repair global settings`, `tidy global settings`, and `heal global settings` are removed. Use `repair user settings`, `tidy user settings`, and `heal user settings`.
- The v7.7.0 announcement said these aliases would be removed in v7.8.0. They survived v7.8.0, v7.9.0, and v7.10.0, and the README wrongly said no temporary aliases remained. This release finishes the removal.
- The README migration table, the workflow guide, and both slides files now point at the current phrases.
