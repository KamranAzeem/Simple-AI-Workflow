# Simple AI Workflow v6.6.1

Released 2026-11-18.

## A thinner AGENTS.md

I got a scare this week. A forced BIOS update almost took out my office laptop, and my first thought was the customer context on it. My second thought was this file, `AGENTS.md`, which every session loads before anything else.

It had grown to 157 lines and 2,399 words. The cap is 2,400 words, so one more rule would have tripped the validator. That is no place for the one file that has to stay small.

So I moved the detail to the procedures that use it:

- The boot scan exclusions now live in `load-context`.
- The two index steps now live in `load-context`.
- Git workspace detection moved to `bootstrap-project`.
- The state-file single-writer rule is one sentence and a pointer to the common policy.
- The long bullets are split.

`AGENTS.md` is now 135 lines and about 1,600 words. There is room for the three config directives I want next: a configurable global user directory, a configurable shell, and an earlier settings load.

## Nothing changed in behavior

Same triggers. Same dispatch order. Same rules, new homes. A procedure that needs the moved detail points at the owner, and the reference test proves every name still resolves. If `AGENTS.md` names a procedure, that procedure exists.

## Why I trust it

The full suite passes, 20 test scripts. The protocol validator passes 8 of 8. The authoring validator passes. A new shape check fails if the file grows back or if the single-writer mechanics return to the router.

## Upgrade

Pull the workflow, run the sync script, and restart the session. That is all.
