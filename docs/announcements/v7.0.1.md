# v7.0.1

This patch release hardens the out-of-band backup scripts.

- Both scripts now stream progress: `Scanning`, `Found project`, `Discovery complete`, `Backing up`, `Backed up`, and a final `Summary`. A long run no longer looks hung.
- The walk prunes heavy directories: `.git`, `node_modules`, `.venv`, `venv`, `vendor`, `target`, `build`, `dist`, `.next`, `.cache`, `__pycache__`, and `.terraform`. Progress starts before the walk, so a large tree no longer looks dead.
- Git Bash keeps the archive when the POSIX mode check cannot run, instead of deleting a good backup. The script reports that ACL verification is unavailable.
- `backup-ai.ps1` walks with an explicit stack, skips reparse points and links, never descends into a matched project, and prints the same progress lines.
- When `icacls` fails, the PowerShell script keeps the archive, prints a warning, and exits non-zero.
- A `tar` failure now prints tar's own message, so the cause is visible.
- Exit codes are unchanged: `0` success, `1` project failure, `2` argument or discovery failure.
- `tests/verify-powershell-scripts.ps1` gains backup progress, summary, and prune checks for the Windows host.
- No policy or procedure change. The ADR records the decision.

Upgrade: pull the clone. The sync script is unchanged.
