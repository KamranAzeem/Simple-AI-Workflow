# v6.9.0

This release adds a `repair global settings` procedure for your global settings files.

Run `repair global settings` and the AI consolidates each file into compact bullets. It keeps `Name` and `Email` under Identity, moves Role, Base, and Certs to a short Profile list, checks every tool on your machine, and trims the bloat. It keeps your personal rules and drops the provenance lines.

The repair takes a backup and writes a manifest before it changes a file. It supports `dry run`. It never prints a secret and never copies your sensitive names.

Use `tidy global settings` or `heal global settings` for the same repair.
