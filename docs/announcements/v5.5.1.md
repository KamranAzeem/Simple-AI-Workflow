# Simple AI Workflow v5.5.1

Released 2026-10-31.

## Planning no longer touches git

A planning request used to open a feature branch before the plan was written. That was backwards. Planning is not implementation, and it should leave your repository alone.

This release fixes the timing.

## What changed

Filing an issue still writes the ticket under `ai/issues/open/` and opens no branch.

Writing and reviewing the plan now happens while the ticket stays in `open/`. No feature branch opens, and no commit is made. The plan file is a working file until you decide to implement it.

The feature branch opens only when you ask to implement the plan. At that point the ticket moves to `ai/issues/in-progress/`, and the plan file joins the branch. From there, the close sequence, the terminal gate, and the release steps are unchanged.

The plan may name the branch that will be created at implementation. The terminal gate still runs when the branch exists, at implementation review and close.

## Upgrade

1. Pull the latest workflow and run the sync script as usual.
2. Nothing else changes. There are no new commands and no new scripts.
3. Open tickets keep working. Planning a new issue now leaves the repository on the current branch.
