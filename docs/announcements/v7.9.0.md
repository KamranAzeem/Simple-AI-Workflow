# v7.9.0

A new project still meant copying `AGENTS.md` and editing a customization by hand. The sync scripts now have an `--init` mode that writes both root files from a role preset.

- `sync --init --role <slug>` writes only `AGENTS.md` and `ai-customization.md`, substitutes the workflow path, and prints the bootstrap hint.
- The eight presets are the whitelist. Unknown roles list the available presets and exit 2.
- The `Default Shell` key is removed from the presets and the template. The optional key stays documented in the guide for manual use.
- New init tests cover all eight roles, refusals, dry run, packaging errors, and rollback, with Bash and PowerShell parity.
- Release: [v7.9.0](https://github.com/KamranAzeem/Simple-AI-Workflow/releases/tag/v7.9.0)
- Upgrade: pull and run the sync; no migration.
