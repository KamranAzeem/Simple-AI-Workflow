# v7.3.0

This minor release adds an idea intake and clarifies the delivery approval. Ideas are now first-class tickets, and the docs say who approves the merge.

- File an idea with `"file an idea"`. It becomes a ticket with `IssueType: Idea`. Grill it, then continue the normal steps or close it with a dated `Won't fix` note. The checkpoint discussed-idea line stays as the backstop.
- `IssueType: Idea` is in the issue policy and the issue template. `Label` keeps its two workability values.
- The implementation request is the approval for the branch, the commits, the push, and the plan's close sequence, including the trunk merge, tag, release, and external writes. The branch approval alone covers only commits and pushes on the branch. Ask only when the plan does not name the action or the request is not an implementation request.
- The guide and README describe the protocol. The protocol modules are authoritative.
- The trigger count is 54.
- Upgrade: pull, run the sync script, and restart the session.
