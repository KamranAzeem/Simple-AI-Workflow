# v6.10.0

This release makes the boot built-in-first. Every file read, search, and listing uses the assistant's built-in tools; the only commands are the version check, directory creation, the read-only index helper, the POSIX metadata step, the global listing and search, the backup archive, and the reported git-ignored fallback.

The boot no longer runs `cat`, `awk`, `sort`, or `find` to build its context. The read-only `support-files/index-protocol.sh` helper calls the existing `--index` mode and sets the effective and conflict fields. If the helper cannot run, the fallback uses built-in tools and reports `index-source=fallback`.

The precedence rule is now explicit: the always-on safety rules bind every level, then the user instruction, then `AGENTS.md` and the common policy, then the customization, then domain policies, then procedure steps.

`Default Shell` is optional. A missing shell or path is reported, and the boot continues with built-in tools.
