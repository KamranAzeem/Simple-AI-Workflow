# Simple AI Workflow v6.2.0

Released 2026-11-09.

## Knowledge stores you can find and trust

Knowledge files now use task-based names of six or fewer hyphenated segments, so the name index matches a task. A file splits only by task topic, never by ticket, incident, date, phase, or environment; a file under 3 KB merges into its nearest topic; a checklist stays one file. Completeness now means every reusable rule, fix, reason, check, identifier, and example, and incident evidence is deleted once the rule is written.

Each store has a 50-file review threshold. The checkpoint reports the count and recommends a repair at 50 or more; the repair merges, deduplicates, deletes evidence, and retires, and it reports any remaining overage. A new topic is never blocked.

A task-to-filename lookup rule tells the AI to read the matching files first, and the global store is searched with shell find and grep. The checkpoint reports closed ticket files, executed plans, and finished artifacts; only the repair deletes.

The protocol's own knowledge names migrate on touch or repair, not in a mass rewrite.

## Upgrade

Pull the workflow, run the sync script, and restart the session. Then run `"repair knowledge files"` once to adopt the task names, topic splits, and the review threshold; add `global` for the global store.
