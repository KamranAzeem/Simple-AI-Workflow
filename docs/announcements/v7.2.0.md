# v7.2.0

This minor release adds an optional team skills root. A team can share reviewed skills the same way it shares lessons, with no new configuration beyond the team store.

- Team skills live in the configured team store's `skills/` directory. The boot indexes name, description, path, and scope only; no body is read.
- Precedence is project, then team, then global. A project skill replaces a team skill, and a team skill replaces a global skill; the AI reports the override.
- Activation is the same `"use skill <name>"` or a single best description match; the team source is announced, the body is task-scoped, and a helper still needs explicit approval.
- The team repository's one-reviewer PR gate and access control are the trust boundary. The protocol does not verify review at boot; you are responsible for the source.
- Contribution is a manual copy into `skills/` plus a PR; one reviewer merges. To retire, remove the package in a reviewed PR; Git history is the record.
- The three-root index keeps the 16 KB bound. No new policy, procedure, or trigger; the counts stay 25 policies, 16 procedures, and 53 triggers.
- Upgrade: pull the clone and run the sync script to pick up the new anchors. The team skills root stays inactive until `Team AI Knowledge Directory` is configured.
