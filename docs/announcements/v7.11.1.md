# v7.11.1

The protocol decision store now carries a checked index, so a maintainer can find a decision without reading the whole store.

- `design-docs/protocol-decisions.md` has a marked index of its dated entries at the top. Each new decision adds one line.
- `tests/test-docs-audit.sh` fails when the index and the headings differ, when a line is missing or extra, or when a dated heading is duplicated.
- `ai-policy-meta.md` states the rule.
- Release: [v7.11.1](https://github.com/KamranAzeem/Simple-AI-Workflow/releases/tag/v7.11.1)
- Upgrade: pull and run the sync; no migration.
