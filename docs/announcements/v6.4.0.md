# Simple AI Workflow v6.4.0

Released 2026-11-13.

## Outbound content scrub

Before an external issue, PR/MR, comment, or release note leaves the project, the AI now applies one scrub contract. It removes secrets in every case. It removes names, internal hosts, URLs, identifiers, ticket keys, and named file paths when the destination is external or belongs to a different audience. A same-customer artifact keeps the customer name and infrastructure detail.

The policy defines two classes. Class A covers internal or same-audience artifacts and keeps names and infrastructure detail. Class B covers external or different-audience artifacts and removes them. Secrets are never overridable.

The AI states the class before drafting, shows the scrubbed text and a category report, and waits for approval. A public destination defaults to redaction and needs explicit approval. Private IP addresses stay; public addresses become documentation addresses. The report lists categories and counts only and stays in chat.

The first release covers external ticket creation, plan-entry comments, close or reopen comments, PR/MR titles and bodies, and release notes. Report sharing, presentation decks, and handoffs get their own steps later. The policy is already general, so those steps reference it without a second contract.

## Test layout

The dev-time test suite now lives in the project-root `tests/` directory, and `support-files/` holds the sync scripts and validators. The six existing fixtures moved with no behavior change.

## Upgrade

Pull the workflow, run the sync script, and restart the session. No repair is needed.
