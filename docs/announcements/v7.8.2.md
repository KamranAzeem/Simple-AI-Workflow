# v7.8.2

Starting a new project still meant editing every section of `ai-customization.md` by hand. This patch ships eight ready-made presets so a new project can start from a full variant and change only what differs.

- Eight presets: cloud-architect, solution-architect, web-developer, mobile-developer, platform-engineer, dba, data-engineer, security-engineer.
- Each preset sets one trait and a matching expertise list. Five pre-fill soc2 and iso-27001 as a suggestion; web-developer, mobile-developer, and dba leave compliance empty.
- The customization guide gains section 11 and three traits: Platform Engineer, Software Developer, and Data Engineer.
- No policy, procedure, or trigger changes. The counts stay 26 policies, 16 procedures, and 59 triggers.
- Release: [v7.8.2](https://github.com/KamranAzeem/Simple-AI-Workflow/releases/tag/v7.8.2)
- Upgrade: pull and run the sync; no migration.
