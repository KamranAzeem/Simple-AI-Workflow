# v7.4.0

The team knowledge store now uses the same directory pattern as the other two knowledge scopes. Lessons move from `lessons/` to `team-knowledge/`, so `global-knowledge/`, `project-knowledge/`, and `team-knowledge/` read the same way.

- The team policy, the publish procedure, and the boot index use `team-knowledge/`.
- The customization guide, the workflow guide, the slides, and the diagram are updated; the HTML deck is rebuilt.
- The fixture moves to `tests/team-alpha/`, and a guard fails if a live file names the old path.
- The repository naming convention and the optional name check are a separate ticket; no helper ships in this release.
- The protocol counts stay at 25 policies, 16 procedures, and 54 triggers.
- Upgrade: pull, run the sync script, and restart the session. If you keep a team store, rename its `lessons/` directory to `team-knowledge/` and update its links.
