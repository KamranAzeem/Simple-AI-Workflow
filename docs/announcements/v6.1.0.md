# Simple AI Workflow v6.1.0

Released 2026-11-09.

## A faster, quieter load context

Load context no longer scans the whole `ai/` tree. It lists only the boot roots, refuses to list or read the excluded local-only paths, and keeps the discovery output under 16 KB.

- Secrets, artifacts, code-review reports, notes, pending items, plans, closed issues, `.git`, archives, and backups are excluded from every boot scan.
- The latest daily checkpoint is read once; the proof reuses it.
- The knowledge, issue, and design-doc indexes use one bounded command.
- The proof is compact: one line per item, counts only, with detail only for a failure.
- The instruction is OS- and terminal-agnostic. It states the intent and a standard Linux Bash example; an AI on Windows or macOS uses equivalent tools. Windows requires `pwsh` 7 or higher; Windows PowerShell 5.x is never used.
- Developers get a read-only `--index` mode on the authoring validator. It prints the module index in one call. End users never run it; the AI builds the index inline.

Windows and macOS were not runtime-verified in this release. Linux and Git Bash are the verified targets; the instruction is the only assurance on the other systems.

## Upgrade

Pull the latest workflow, run the sync script to update `AGENTS.md`, and restart the session. The procedure modules update from the clone.
