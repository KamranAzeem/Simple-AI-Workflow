# Simple AI Workflow v6.3.0

Released 2026-11-09.

## Skills on demand

Skills are a new layer for narrow, task-specific instruction packages. Drop in `ai/skills/<name>/SKILL.md` in the workflow clone for a global skill, or in your project root for a local skill. A project skill with the same name overrides a global one, and the AI reports the override.

The index reads only the package name, description, path, and scope at boot. The body loads for one task when you say `"use skill <name>"` or when a single best description match applies. The description is one line of at most 200 characters; the directory name matches `name`.

Skills are outside the policy and procedure trigger namespace. A skill cannot override `AGENTS.md`, a policy, your instructions, or `ai-customization.md`; a helper script needs your explicit approval and stays inside the package. The protocol does not scan a skill. You are responsible for the source of every skill you drop in.

The checkpoint records the skills count and package names, reports a new package, and never edits a skill. The repair never touches skills, lint covers `SKILL.md`, and the sync script does not copy them. v1 ships the subsystem and examples; bundled third-party skills come later.

## Upgrade

Pull the workflow, run the sync script, and restart the session. Put global skills in the clone's `ai/skills/` and project skills in your project's `ai/skills/`. No repair is needed.
