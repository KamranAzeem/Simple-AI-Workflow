# v7.2.1

This patch corrects the post-compaction recovery documentation. The procedure is manual, and the docs now say so.

- Post-Compaction Recovery does not run automatically. No harness currently provides a reliable hook that fires after compaction and re-injects the protocol.
- After you notice a compaction, type `"run post-compaction recovery procedure"`. The reply starts with `[Reloading key files into context...]`.
- A pre-compaction hook only warns you before the summary. It cannot inject the rules into the next turn, so it can prompt you to run the recovery but cannot run it.
- The procedure title, the always-on rule, the workflow guide, the slides, the setup guide, the comparison table, the README, and the project knowledge note are corrected.
- The reload steps and the no-state-file rule are unchanged.
- Upgrade: pull, run the sync script, and restart the session. After each compaction, run the phrase yourself.
