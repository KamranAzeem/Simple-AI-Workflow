# Shared Knowledge Base: CSS Architecture
- **Approach**: Modular CSS (BEM naming convention).
- **Tooling**: Vanilla CSS (no Tailwind/frameworks).
- **Performance**: Minimize global scope; prefer component-scoped styling.
- **Organization**: Follow `src/styles/components/<component>.css` structure.
