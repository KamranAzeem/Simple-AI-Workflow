# Protocol Name Migration Map (2026-10-06)

What this is: on 2026-10-06, procedures, steps, and tiers moved from single letters and positional numbers to stable ALL-CAPS kebab names. Names never renumber, so a reference to a name stays correct when the protocol changes around it. This map translates every old reference to its new name.

## Where old names remain on purpose

- Daily checkpoints under `ai/daily-checkpoints/` and closed tickets under `ai/issues/closed/`: these are the historical record and are not rewritten.
- Ordinary "step" usage in `docs/multi-agent-runbook.md`, `docs/example-learning-session-runbook.md`, `docs/vscode-cline-provider-setup-for-beginners.md`, and the sync scripts: not protocol steps, left unchanged.
- `ai-customization.md` files in other projects: the sync script does not rewrite them; update the old reference on your next edit.
