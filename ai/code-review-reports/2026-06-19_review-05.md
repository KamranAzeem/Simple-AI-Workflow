## Major

- [ ] `support-files/sync-agents-md.ps1:82` — **Workflow Dir replacement uses wrong back-reference**: pattern has 4 capture groups — `$1` = prefix+opening backtick, `$2` = `Framework|Workflow`, `$3` = old path value, `$4` = closing backtick. Replacement is `'$1' + $targetWfDir + '$3'`, which substitutes `$3` (old path) instead of `$4` (closing backtick). Result: closing backtick is dropped and old path is appended to the new one. Correct replacement: `'$1' + $targetWfDir + '$4'`.

- [ ] `support-files/sync-agents-md.ps1:83` — **User AI Dir replacement has the same class of bug**: pattern groups are `$1` = prefix+opening backtick, `$2` = old path, `$3` = closing backtick. Replacement `'$1' + $targetUserDir + '$2'` appends the old path instead of the closing backtick. Correct replacement: `'$1' + $targetUserDir + '$3'`. (The companion `.sh` script at lines 104/108 handles this correctly by not capturing the value, so `\3` is the closing backtick — the `.ps1` is the only broken version.)
