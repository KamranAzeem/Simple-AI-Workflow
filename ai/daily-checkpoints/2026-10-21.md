# Daily Checkpoint 2026-10-21

## Coding base policy

- Created the coding base policy `ai/policies/ai-policy-coding-base.md` with expertise token `coding-base`. It is opt-in, language-neutral, and owns only code construction: module and interface design, functions and naming, data and state, configuration, errors, concurrency, comments, and the no-disturbance rules.
- Telemetry is an opt-in gate, not a mandate: the AI asks when the project has no telemetry standard or the code is non-production, defaults to no for examples, exercises, one-off scripts, throwaway prototypes, and command-line tools, and to yes for production applications, then waits for the answer and skips on a no.
- The policy was iterated through three shapes in one session: a telemetry-mandatory outline, an operational baseline that filled ten gaps, and finally a thin core plus pointers. Each cross-cutting concern now points at its owner, and the domain pointers are read instructions so enabling `coding-base` alone still pulls the right domain policy on demand.
